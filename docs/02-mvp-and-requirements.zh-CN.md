# MVP 需求与优先级

[English](02-mvp-and-requirements.md) | 简体中文

**拟定范围 · 2026-11-18 · 尚未选定实现技术栈**

## P0 — 完成一档真实可播放的节目

| 能力 | 最小验收条件 |
| --- | --- |
| 单曲输入 | 选择一首完整且身份明确的录音，不要求分析文件内部片段 |
| 元数据门槛 | 提供曲名、音乐人及足够可靠的录音身份；无法识别则明确报错 |
| 私人曲库播放 | 索引少量用户合法拥有的音频，展示基础曲库与播放队列 |
| 有依据的音乐研究 | 核实作品、参与音乐人、演出事件、录音及发行的关键事实 |
| 录音版本关系 | 区分 Dylan 1964 年、The Byrds 1967 年和 1992 年现场合唱版，知道它们来自**同一个 Work** |
| 节目策划 | 先生成主题、选曲、推荐理由和时间预算，再写主持稿 |
| 自然语音 | 中文 TTS 自然，英文音乐人姓名发音正确，音色与语速一致 |
| BGM 与混音 | 原创/授权音乐床、音量 Ducking 和自然淡入淡出，不混入未经授权的歌曲 |
| 时间轴播放器 | 支持口播与合法完整录音的顺序播放、暂停、跳过及推荐理由 |
| 双语文档 | 同一次修改同步维护英文与简体中文内容 |

## P1 — 逐步扩展

- 台式机/NAS 的持久化曲库索引与多设备访问。
- 基于用户授权的收藏和收听历史形成个人音乐画像。
- 延展音乐人、不同录音和合作关系的知识网络。
- 可编辑的节目方案、播放来源解析及失败恢复。
- 在具有合法音频分析权限时引入声学特征与音频 Embedding。
- 明确授权的云流媒体接入及可选本地模型部署。

## 首版明确不做

- 完全无标签录音的音频指纹自动识别。
- 歌曲文件内部段落检测和乐谱对齐。
- 通用短视频神曲、任意声音与全部流派覆盖。
- 完整取代所有云流媒体平台，也不宣称完全零持续成本。
- 未经许可截取商业歌曲；不得通过破解或抓取 DRM 音频来混音。
- 强制全本地模型、生产级 NAS 多用户管理或稳定公开 API。

## Demo 验收

1. 选中 1992 年的正确现场录音后，生成可检查的节目方案。
2. 不混淆作品、发行、演出和参演者，历史事实可追溯来源。
3. 从现场版到原版，再到 1967 年演绎的推荐路径具有音乐与历史依据。
4. 约 15 分钟的目标随实际合法音频文件和口播时长调整。
5. TTS 自然、事实清晰、BGM 不影响人声。
6. 缺失元数据或歌曲来源不可用时，用户能理解失败原因。

## 建设顺序

少量合法可播放的曲库 → 身份验证 → Music Context Pack 与关联关系 → 节目策划 → 中文 TTS/BGM → 时间轴播放器 → 更完整的本地音乐服务器和用户画像。
