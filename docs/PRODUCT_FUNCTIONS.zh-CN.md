# 产品功能库

[English](PRODUCT_FUNCTIONS.md) | 简体中文

**本表是产品能力的唯一稳定清单**，参照 [Meeting Minutes 功能表](https://github.com/JohnnyBGoodeLithium/Local-Video-Meeting-Minutes/blob/main/docs/PRODUCT_FUNCTIONS.md) 的四级编号、成熟度与证据规则。本表不写样例歌曲内容、不替代需求文档、不当作发布日志。

- **固定编号：** `模块.能力域.能力组.叶功能` 四级，功能正式上线后不重排、不复用。
- **重要度：** P0 = 核心能力或安全边界；P1 = 主旅程；P2 = 运营/效率；P3 = 体验打磨。
- **成熟度：** 规划中 / 已实现待验证 / 实验中 / 已验证。**目前全部处于“规划中”**，功能描述不能当作代码已实现的证据。
- **首次版本、增强版本及 Git：** `—` 代表**尚未上线、没有对应实现证据**，只有实际验证后才回填版本与提交。
- **证据：** 真实实现以代码、测试和 Git 为准；摘要见[当前状态](STATUS.zh-CN.md)，产品范围见[MVP](02-mvp-and-requirements.zh-CN.md)。
- 普通 Agent 不需要默认阅读全文；仅在功能盘点、正式发布核查或修改功能合同时读取。

## 能力域

下表与 README 中的七个逻辑模块属于不同粒度：这里按功能编号追踪交付能力，完整系统分工请看[README](../README.zh-CN.md#4-产品由哪些大模块组成)与[架构](04-conceptual-architecture.zh-CN.md)。

| 模块 | 职责 | 首版路径 |
| --- | --- | --- |
| 1. 曲库与来源 | 复用存储、识别录音及合法播放来源 | 优先授权平台曲库数据，音频可选 |
| 2. 音乐理解 | 元数据、可信知识、可选声学与个人上下文 | 元数据+可信关系优先 |
| 3. 电台策划 | 从现有曲库挑选可讲述的关联，生成节目 | 先策划、后写稿 |
| 4. 模型和音频 | 本地/云端 LLM、TTS、BGM、明确的数据边界 | Provider 解耦 |
| 5. 播放与延续 | 可执行时间轴、推荐解释、交互与失败处理 | 完整歌曲+原创主持音轨 |
