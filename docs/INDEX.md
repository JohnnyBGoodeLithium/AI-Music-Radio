## Read the smallest relevant context / 只阅读当前所需

- Product decision: `AGENTS → STATUS → INDEX → PRODUCT`
- Architecture/model choice: `AGENTS → STATUS → INDEX → ARCHITECTURE`
- Feature review or release audit: `AGENTS → STATUS → INDEX → PRODUCT_FUNCTIONS`
- Demonstration/audio script: `AGENTS → STATUS → INDEX → DEMO`

The feature inventory is **not** a default full-context read; avoid duplicating feature rows in STATUS and README. Specific song details belong **only** in the Demo. A former example file is retained as an old-link stub, not as another active specification.

功能库不属于常规任务的默认全文上下文。不要在 README 和 STATUS 重复整张功能表；歌曲案例**只**属于 Demo。旧示例路径仅保留历史链接兼容，不再作为另一份规格。
