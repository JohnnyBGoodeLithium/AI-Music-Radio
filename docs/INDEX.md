## Canonical responsibilities / 唯一真源职责

- **STATUS:** current validated maturity and next priorities / 当前完成度、验证边界和近期重点。
- **Product:** positioning, personas, persistent promises / 产品定位、用户画像、长期产品边界。
- **MVP:** requirements, non-goals and acceptance criteria / 范围、非目标、验收条件。
- **Demo:** seed identity, episode storyline, running order and original narration / 种子录音、节目叙事、时间轴和原创主持词。
- **Architecture:** identity/entity model, evidence, rights, processing contracts / 音乐实体、来源证据、版权及处理架构。
- **Open Questions:** decisions and unresolved choices / 已明确决策及待研究事项。
