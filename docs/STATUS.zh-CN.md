# 当前状态

[English](STATUS.md) | 简体中文

**2026-11-18 · 仅完成概念与文档**

本仓库尚未实现或验证音乐服务器接入、真实音乐库索引、音乐理解、推荐、LLM Provider、TTS 生成或可运行电台播放器。

## 产品基线

- **基础工具价值：** 用户合法拥有的音乐文件由现有个人存储/音乐服务器基础设施提供。
- **差异化：** AI 音乐研究、曲库优先的可解释关联，以及自然语音电台节目。
- **输入：** 一首身份明确的完整录音/文件；缺少必要身份信息允许报错；不做歌曲内部段落识别。
- **音乐理解：** 优先元数据与可信关系；整曲音频特征可选且须符合授权。
- **基础设施：** Lenovo Smart Storage **只是集成候选**，尚未确认存在可用的音乐服务 API；先用本地目录测试。
- **模型边界：** TextLLM / TTS 可选择本地或云端 Provider，需显式配置，不静默上传数据。
- **当前产物：** 中英文产品文档、架构、单独的 Demo 案例、带稳定编号的[功能库](PRODUCT_FUNCTIONS.zh-CN.md)。**功能库所有能力仍为“规划中”。**

## 近期重点

1. 验证本地目录索引与合法可播放的测试曲库。
2. 实现最小录音身份识别及 Music Context Pack。
3. 展示以用户曲库为优先、有证据的关联选曲与节目方案。
4. 接入可配置的 LLM/TTS、原创/授权 BGM 和真实节目时间轴。
5. 在主路径验证后调查 Lenovo Smart Storage/现成音乐服务器的接口可行性。

## 尚未验证

没有完成真实歌曲播放、音频授权测试、元数据准确性、本地/云端模型调用、个人画像、音频特征、TTS 质量、服务器集成、远程访问、时延或成本评测。
