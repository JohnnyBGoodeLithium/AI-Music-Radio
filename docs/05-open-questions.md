# Open Product and Technical Questions

English | [简体中文](05-open-questions.zh-CN.md)

The [README](../README.md) is the complete product overview. This document holds **questions that still require evidence**, rather than restating positioning.

| Question | Why it matters | Next evidence |
| --- | --- | --- |
| Can Apple Music Windows reliably export original **Play Count and Date Added**? | Baseline personal behavioral data | Per-track comparison of app UI, exports and catalog coverage |
| How to match the same recording across sources while preserving source metrics? | Trustworthy personal history | Compare source IDs, recording identity, count semantics |
| What statistics and capabilities does stock Music Assistant already expose? | Avoid rebuilding functionality | Run actual catalog APIs, Host/Show/Segment, queues |
| Can upstream AI Radio accept an external editorial plan and segment feedback? | Determine extension point | Test show input, rendering, partial edits and asset reuse |
| Does the report/personal context really outperform generic recommendations? | Validate the differentiator | Side-by-side listening and factual review of the same topic |
| Which providers allow catalog read, lawful playback and audio manipulation? | Rights-aware production | Independently verify each entitlement |
| Does the frontend need replacement? | Keep the project small | Test existing API with monochrome low-fi user journey |

Planned does not mean implemented. [Actual status](STATUS.md). Named recordings and scripts remain [Demo-only](03-my-back-pages-demo.md).
